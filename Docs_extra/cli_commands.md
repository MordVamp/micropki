# Документация командной строки (CLI) MicroPKI

Утилита `micropki` — это инструмент командной строки, реализующий инфраструктуру открытых ключей (PKI). Данный документ содержит полный список поддерживаемых команд и их назначение.

## Основной синтаксис

```bash
micropki [команда] [подкоманда] [флаги]
```

---

## 1. Команды Удостоверяющего Центра (`ca`)

Группа команд для управления корневым (Root CA) и подчиненным (Intermediate CA) центрами сертификации, а также выпуска и отзыва сертификатов.

* `micropki ca init`
  Инициализация корневого центра сертификации (Root CA). Создает самоподписанный корневой сертификат и шифрует закрытый ключ (с поддержкой сохранения на USB).
  *Флаги:* `--subject`, `--key-type`, `--key-size`, `--validity-days`, `--passphrase-file`, `--out-dir`, `--usb-path`.

* `micropki ca issue-intermediate`
  Выпуск сертификата промежуточного центра сертификации (Intermediate CA), подписанного корневым ключом.
  *Флаги:* `--root-cert`, `--root-pass-file`, `--usb-path`, `--subject`, `--passphrase-file`, `--out-dir`, `--db-path`.

* `micropki ca issue-cert`
  Выпуск конечного сертификата (для сервера, клиента, электронной подписи кода и т.д.) на основе шаблона и CSR.
  *Флаги:* `--ca-cert`, `--ca-key`, `--ca-pass-file`, `--template`, `--subject`, `--csr`, `--out-dir`, `--db-path`.

* `micropki ca issue-ocsp-cert`
  Выпуск специализированного сертификата для OCSP-ответчика.

* `micropki ca gen-crl`
  Генерация списка отозванных сертификатов (CRL).

* `micropki ca revoke <serial>`
  Отзыв сертификата по его серийному номеру.
  *Флаги:* `--reason`, `--db-path`.

* `micropki ca compromise`
  Компрометация ключа или сертификата (немедленный отзыв с пометкой keyCompromise).
  *Флаги:* `--cert`, `--reason`, `--db-path`.

* `micropki ca list-certs`
  Отображение списка всех выпущенных сертификатов, сохраненных в базе данных.

* `micropki ca show-cert`
  Отображение детальной информации о конкретном сертификате.

## 2. Команды HTTP-Репозитория (`repo`)

Управление HTTP-сервером, который раздает публичные сертификаты, CRL и принимает запросы на выпуск. Имеет защиту от DDoS (TCP HTB Rate Limiting).

* `micropki repo serve`
  Запуск HTTP-сервера репозитория PKI.
  *Флаги:* `--host`, `--port`, `--db-path`, `--cert-dir`, `--rate-limit`, `--rate-burst`.

* `micropki repo status`
  Проверка состояния и доступности сервера репозитория.

---

## 3. Команды OCSP-Ответчика (`ocsp`)

Управление сервером Online Certificate Status Protocol (OCSP).

* `micropki ocsp serve`
  Запуск сервера OCSP для проверки статуса отзыва сертификатов в реальном времени.
  *Флаги:* `--port`, `--db-path`.

---

## 4. Клиентские операции (`client`)

Команды для конечных пользователей системы (генерация запросов, проверка статуса).

* `micropki client gen-csr`
  Генерация закрытого ключа клиента и запроса на подпись сертификата (CSR).
  *Флаги:* `--subject`, `--san`, `--out-key`, `--out-csr`.

* `micropki client request-cert`
  Отправка CSR-запроса на удаленный сервер репозитория для автоматического выпуска сертификата (по API).

* `micropki client check-status`
  Проверка статуса сертификата (через OCSP или CRL).

* `micropki client validate`
  Полная криптографическая валидация цепочки сертификатов от конечного узла до корневого CA.

---

## 5. Аудит и логирование (`audit`)

Команды для работы с криптографически защищенным журналом аудита.

* `micropki audit query`
  Поиск и фильтрация событий в журнале аудита.
  *Флаги:* `--operation` (например, "compromise_key").

* `micropki audit verify`
  Проверка криптографической целостности журнала аудита (валидация цепочки хэшей Hashchain и проверка подписей HMAC (неотказуемость)).

---

## 6. База данных (`db`)

Управление SQLite базой данных PKI.

* `micropki db init`
  Первичная инициализация схемы базы данных PKI.
* `micropki db status`
  Проверка целостности и статуса подключения к БД.
