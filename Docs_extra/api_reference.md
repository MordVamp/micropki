# API Reference

The MicroPKI Repository server (`micropki repo serve`) exposes a RESTful API over HTTP for querying certificates, CRLs, and dynamically requesting new certificate issuances.

## Base URL
By default, the repository runs on: `http://<host>:<port>` (e.g. `http://localhost:8080`)

---

## 1. Get CA Certificate
**Endpoint**: `GET /ca/{level}`

Retrieve the public certificate for the Root or Intermediate CA.

- **URL Parameters**:
  - `level`: Must be either `root` or `intermediate`.
- **Response**: `200 OK`
  - **Content-Type**: `application/x-pem-file`
  - **Body**: The PEM-encoded CA certificate.
- **Errors**:
  - `400 Bad Request`: Invalid CA level.
  - `404 Not Found`: CA certificate file does not exist on disk.

---

## 2. Get End-Entity Certificate
**Endpoint**: `GET /certificate/{serialHex}`

Retrieve an issued certificate from the database by its serial number.

- **URL Parameters**:
  - `serialHex`: The hexadecimal serial number of the certificate (without `0x`).
- **Response**: `200 OK`
  - **Content-Type**: `application/x-pem-file`
  - **Body**: The PEM-encoded certificate.
- **Errors**:
  - `404 Not Found`: Certificate with the specified serial number is not in the DB.

---

## 3. Get Certificate Revocation List (CRL)
**Endpoint**: `GET /crl?ca={level}`

Retrieve the latest CRL generated by the CA.

- **Query Parameters**:
  - `ca` (optional): The CA level to fetch the CRL for (`root` or `intermediate`). Defaults to `intermediate`.
- **Response**: `200 OK`
  - **Content-Type**: `application/pkix-crl`
  - **Body**: The PEM-encoded CRL file.
- **Errors**:
  - `404 Not Found`: CRL has not been generated yet.

---

## 4. Request Dynamic Certificate Issuance
**Endpoint**: `POST /request-cert?template={templateName}`

Submit a Certificate Signing Request (CSR) to be automatically signed and returned.

- **Headers**:
  - `X-API-Key`: **REQUIRED**. Must be `changeme` (Educational demo default).
  - `Content-Type`: `application/json` OR `application/x-pem-file`.
- **Query Parameters**:
  - `templateName`: The template profile to use (e.g., `server`, `client`, `code_signing`).
- **Request Body**:
  - If JSON: `{"csr": "-----BEGIN CERTIFICATE REQUEST-----\n..."}`
  - If PEM: Raw PEM-encoded CSR data.
- **Response**: `201 Created`
  - **Content-Type**: `application/x-pem-file`
  - **Body**: The newly issued PEM-encoded certificate.
- **Errors**:
  - `401 Unauthorized`: Missing or incorrect `X-API-Key`.
  - `400 Bad Request`: Missing template or malformed CSR.
  - `500 Internal Server Error`: Signing execution failed (e.g., policy constraints violated).
